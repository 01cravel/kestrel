# Market history data contract

Kestrel's swing-radar history is private local research data. It is stored in
`.kestrel-data/market-history/`, which Git ignores. API credentials are read only
from `MASSIVE_API_KEY` and sent in an authorization header; they are never saved.

## Safe preview

```sh
python3 market_history.py plan
python3 market_history.py status
```

Neither command requires an API key or makes a network request. The default plan
downloads from the free plan's two-year boundary through today. Its trainable
range ends 14 days earlier so five-session labels can mature. A specific range
can be previewed with `--start YYYY-MM-DD --end YYYY-MM-DD`.

## Download and resume

```sh
MASSIVE_API_KEY="your-key" python3 market_history.py sync
```

The sync uses Massive's official Grouped Daily endpoint for every weekday and
can restart safely: completed dates are skipped. It also takes monthly
point-in-time snapshots of active US identities, retains inactive/delisted
identities at the range end, and downloads splits and dividends for the requested
range. HTTP 429 and temporary server/network failures
are retried with backoff. The default five-request-per-minute limit is intentionally
conservative for a basic plan.

Grouped prices are explicitly split-adjusted by Massive. Dividends are stored as
separate cash events; Kestrel compounds their split-adjusted cash amounts into a
separate total-return close for labels while preserving the original bar. Every raw
response is gzip-compressed and retained by SHA-256 digest with its source request
ID and retrieval timestamp.

The downloader also requests up to 14 calendar days beyond the selected end so
the following five SPY sessions can mature. If that tail is unavailable—for
example, the range ends near today—the affected labels remain quarantined.

## Training contract

The SQLite database contains:

- `daily_bars`: one split-adjusted OHLCV observation per session and ticker;
- `reference_snapshots`: active and inactive/delisted identities, including FIGI
  and CIK where supplied;
- `corporate_actions`: complete raw split and dividend records;
- `sessions`: resumable per-date completion markers;
- `fetch_audit`: source path, safe parameters, timestamp, request ID, digest and
  raw-file location.
- `swing_observations`: shared Phase 1 inputs, decisions, reasons, action flags,
  policy version, adjusted stock/SPY closes and t+1/t+5 labels generated by
  `swing_radar_policy.py`.

`MarketHistoryStore.iter_daily_bars(start, end)` exposes untouched market bars;
`iter_swing_observations(start, end)` is the stable, policy-versioned interface for
the next modelling phase. The raw interface intentionally returns all Grouped Daily observations.
The `eligible_equity` field in reference data is a transparent hint for common
shares and depositary receipts, not a hidden deletion rule. Final liquidity,
price, exchange, ETF and investability rules belong in Phase 1 policy.

Massive Grouped Daily does not contain point-in-time market capitalisation, and
the pipeline never substitutes a current value. `market_cap` therefore remains
null and Phase 1 correctly marks eligibility as unknown until a timestamped
historical shares/market-cap source is added. A bar proves that the symbol traded
on that session. Monthly identity snapshots mean a new or changed identity can
remain unresolved until the next snapshot rather than being backfilled with
future knowledge.

Run a fail-closed integrity check after syncing:

```sh
python3 market_history.py validate --start 2024-08-01 --end 2026-08-01
```

## Universe outcome bridge

`universe_outcomes.py` reads the retained references, sessions and
`swing_observations` after each daily universe freeze. It appends a pending,
complete, missing, conflict or delisted-complete state for every frozen member.
An ordinary path starts on the first session after the decision cutoff and must
cover every archived market session with one clean, same-currency,
policy-versioned total-return close. Ticker changes are accepted only when the
reference archive maps both symbols to the frozen stable identity.

Inactive references preserve listing-state changes but do not supply proceeds.
A terminal result additionally needs matching, timely structured SEC or official
issuer terms in `issuer_events`. Pure cash terms end at evidenced per-share
proceeds; stock or mixed terms follow the stable successor through the annual
horizon. Missing terms, missing sessions, late records, currency changes,
conflicts and invalid hashes append an incomplete state. Re-running unchanged
evidence adds nothing; later corrections append without rewriting history.
